How this assessment works

Pitch: full credit within 35 cents, tapering to zero at 100 cents. Coverage: matched attacks divided by evaluable matches, omissions and extras. Rhythm: local beat interpolation, allowing phrase timing. Expressive mode weights these 50 / 30 / 20; target-tempo mode uses 45 / 25 / 20 plus 10% tempo. Available components are reweighted. Frequency supplies pitch; it is not counted twice. Low-confidence sound is kept separate from confirmed errors.

Accelerando

Built around your playing.

On-device CREPE tiny neural pitch tracking, from the pretrained CREPE model via TorchCREPE. ONNX Runtime runs inference locally. VexFlow renders notation. Accelerando supplies note grouping, alignment, scoring, practice reports and the interface.

This build assesses a single pitched melodic line from many instruments. It does not assess chords, ensembles, percussion or tone quality. Microphone acoustics and note attacks affect accuracy; uncertain sound may be ungraded. Actual performance and latency must be checked on your tablet.

MusPal’s publicly described practice workflow informed the interaction research; no MusPal assets or model are included. See the included open-source licenses.
